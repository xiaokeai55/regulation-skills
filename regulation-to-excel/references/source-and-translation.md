# 来源核验、完整覆盖及翻译校对

## 原文获取及版本

以用户链接为首要入口，核对法规名称、编号、发布机关、司法辖区、正文语言、发布日、生效日、效力状态和版本。法规清单“链接”列不是云厂商合规页面列；不要误用AWS等第三方概述作为法律原文。

沿用户链接进入的官方“全文”“下载”“现行版本”属于同一来源链。记录入口和最终正文地址，不假称最终下载URL就是清单中的入口URL。核验内容与待整理法规、版本或指定范围不符时，先说明具体问题，请用户检查URL或确认替代来源后继续。403、登录页或无法下载只表示尚未核验，不等于链接错误。可以先查找同一发布机关或官方法律数据库的候选正文并给出可复核地址，但不能在需要用户确认时自行替换后开始生成。只剩非官方镜像时，核对其法规身份、版本及内容；不能独立核验则说明限制并请求官方文本，不能默认当作已核实原文。

发现新版时，将用户URL所指版本与新版的版本标识、官方来源及生效状态告知用户，请其确认使用哪个版本。新版已发布但尚未生效时同样说明，不能把“最新发布”当作“现行生效”。等待版本选择期间暂停提取、翻译、映射和Excel生成；可以继续核验候选版本。用户已针对此次发现的新版明确作出选择时，记录该确认即可，不重复询问。

同一法规的正式原语文本与官方译文不一致时，以有法律效力的文本为准，记录差异。用户明确选择历史或截至某日版本时遵守选择。无特别要求且未发现需确认的版本差异时，采用核对时官方现行合并文本；不自行合并待生效文字。不把修订历史日志列入表格。将URL核验结果、新版发现情况及用户确认的版本记录到manifest.source_review，不能为通过检查而虚构确认。

保留下载文本或可复核的来源快照在工作目录，并记录检索核对日期。动态页面只保存导航或空壳不算取得全文。

## 当地语言、英语和中文

每份输出均包含当地语言、英语和简体中文。先根据司法辖区、发布机关、法规正式语言及用户要求确定当地语言；有多个当地／官方语言且当前上下文不能确定目标语言时，仅就该选择询问。不能因为收到英文文件就默认当地语言为英语。当地语言确为英语或中文时，仍填满E／F／G对应栏，必要时重复同一语言内容，不编造另一种当地语言。

拿到英文文件后，优先检索发布机关及官方法律数据库中同一法规、同一选定版本的当地语言文件。找到且核验一致时，以当地语言原文为依据，并核对可用的官方英译；发现新版或实质版本差异仍按版本确认规则处理。不能混用不同版本来凑齐三种语言。

经检索仍无法取得当地语言官方文件时，可直接按用户已授权的方式，将核验过的英文文本分别翻译成当地语言和中文。记录检索入口、结果及核对日期，说明“未能取得”而不武断断言原文不存在。E列当地语言属于非官方译文，表头和来源备注必须注明“非官方译文，译自英文”；F列保留完整英文来源文本及真实来源，不将其或回译升级为官方／有法律效力原文。只有部分当地原文可用时，不静默拼接原文与回译：先明确缺失范围并逐条记录实际依据，按各行来源调整生成与校验，表头和备注披露混合来源。

当地原文存在时不必重复翻译该语言，英语已有同版可靠文本时可核对后保留，中文已有准确简体文本时可核对后保留；所有自译均标明非官方。三语要求也适用于开头适用性说明、定义、附件、标题及经确认的部分摘录，不扩展为改写内部实践原文。

三种语言分别记录来源地址或文件定位、同版核对依据和文本身份。官方发布不自动等于有法律效力原文；官方译文与自行翻译分别标为“官方译文”和“非官方译文”。G使用简体中文官方原文时标“原文”；自行将繁体原文或译文转为简体时，保留其来源身份并附“繁转简，非官方转换”，不得声称转换后的文字为官方发布的简体文本。E保留当地来源原有文字。上述信息写入language_plan.columns、表头及既有来源备注。

## 完整提取

先清点原始文件全目录和页码，建立“章—节—条—款—子项—附表”的清单，再提取内容。不得从关键词命中条款倒推完整范围。全文整理必须包括目的、范围、定义、客户金融业务专属条款、执行处罚、附件、附表及无对应实践内容。

HTML／MHTML：保留真实条文表格、表头、嵌套表格和直接正文。防止只提取外层单元格或把内层数值条目误认成新条号。原文数字编号缺句点仍可能是独立规则，例如“10 Enhanced CDD”；依标题和上下文判断，不能只依“数字+句点”正则切分。

PDF：核对跨页段落、页眉脚、双栏阅读顺序、表格和脚注；扫描件使用OCR后逐页视觉核验编号、数字和符号。文本层为空、缺页或乱码必须处理。脚注承载条件、定义或例外时应纳入对应条款，不能作为版面噪声删除。

### 适用性说明与经确认的摘录范围

法规开头规定适用主体、业务或地域范围、适用条件及例外的实质内容，应按原顺序单独纳入Excel，并完整填写当地语言、英语和中文；当地语言译自英文时标明其非官方译文身份。仅整理IT、外包等部分要求时，仍纳入理解该范围所需的开头适用性说明及必要定义。没有实践证据也不能删去；按既有H、I至M留空规则处理。仅封面、目录或无实质内容的标题不新增控制行。

遇到超长条款，或金融、治理等要求与本次技术要求混合的条款，可以提出只摘录相关款项的方案。先指出父条号、具体款项／子项、拟保留的引导句及结尾和整理范围，请用户确认。不能因篇幅长、排版困难或某些子项没有实践证据而自行省略。用户同意本次具体摘录范围后再按该范围整理；已有明确且适用于本次款项的选择不重复确认，泛称“继续”不能代替尚未解决的摘录范围选择。

摘录使用原文原句，保留限定适用主体和义务的引导句、条件、例外、职责说明、交叉引用及必要结尾，不因截取片段改变法律效果。E、F、G逐一对应，完整保留选定范围的原文及译文；C保留父条号和实际款项／子项，N明确写明“摘录”及具体范围。regulation.scope及source_note记录本次范围，工作资料保留真实确认依据、原文定位及排除范围；不能将选择性摘录称为整条或全文覆盖。

用户选择保留整条时完整整理，超过单元格容量沿原文层级拆分为连续行；已确认的摘录内容仍超过容量时同样拆分。摘录授权不等于允许摘要、改写或截断选定内容。

核查以下不变量：

- 全文整理时，所有目录中的实质章节、定义、附表和附件均有内容对应；部分整理时核对已确认范围、必要适用性说明和定义的完整对应。正文引用的必要附件未随文件取得时不能宣称该范围完整。
- 条号按原顺序，不遗漏或重复；原文本身缺号／编号异常需保留并备注，不补造法律条号。
- 完整条款的全部子项、嵌套层级、否定及例外保留；经确认摘录的条款，核对选定款项及必要上下文完整，并清楚标示未纳入范围。分段重组后与原始条文对应范围逐字或经限定空白规范化比对。
- 数字、单位、币种、百分比、时限、年月日、数学符号及对其他条号的引用与原文一致。
- 未加工正文与提取结果逐节或逐页核对。不要仅在由同一错误提取生成的两份数据之间验证一致。
- 官方保留的“已废止／已删除”占位可记录当前状态；不要恢复旧文或添加修订沿革。
- 仅有名称、封面、目录或无实质内容的章节标题无需独立成控制行，但不得误删章节无编号正文。

## 翻译校对

在全量翻译前确定术语表，并在全文件一致使用；不要把rulebook、regulation、communiqué等不同文种、责任人、合规官和洗钱报告官相互混淆。外部法规的定义交叉引用必须保留，不凭记忆扩展定义。

逐条对照原文和译文，至少检查：

| 关注点 | 要保留的法律效果 |
|---|---|
| 主体及对象 | 银行／VASP／董事会／员工／客户／供应商；资金、虚拟资产、个人数据不能混用 |
| 强制程度 | shall／must／should／may的法律效力及文件自身解释；不得把建议或许可译为强制 |
| 条件与例外 | if、unless、subject to、notwithstanding、where applicable；保留例外适用范围 |
| 数量及比较 | 超过、等于或超过、不少于、不超过、最低／最高；阈值与单位不变 |
| 时间 | 立即、小时、日历日、工作日；收到／发现／生效／通知之日起的不同起算点 |
| 列举关系 | 包括但不限于、及／或、至少、可选条件；不改变并列或选择逻辑 |
| 否定及范围 | not、prohibited、no effect、仅限；不能丢失否定词 |
| 层级及引用 | 原编号、子项、附表、其他法律和手册引用全部准确 |

不为了简练把全文翻译缩成摘要。译文可使用自然中文，但每个实质限定和要求都必须有对应表达。三语都要与实际来源逐条核对：有当地语言官方原文时据此核验英语和中文；仅取得英文时直接据英文核验当地语言译文和中文，不把生成的当地语言译文当作新的原文再次转译中文。关键数值／期限、复杂例外、法定名称、重复定义和金融专项条款至少做第二次复核；不得把自动一致性检查描述为独立法律审查。

无法判断时回到原语上下文、官方定义和正式译文；仍有重大歧义则注明并请求必要信息，不静默选用可能错误的法律效果。
